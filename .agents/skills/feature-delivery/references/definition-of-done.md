# Definition of Done

Acceptance criteria complete; public behavior tested; strict typing/lint/format passing;
bounded I/O and sanitized errors; structured logs and appropriate signals; security reviewed;
contracts/migrations reproducible; relevant architecture, runbooks and developer docs updated.
No unexplained regressions or unexecuted claims. Only applicable checks are required.
At final Phase 0 delivery, all requirements in docs/roadmap/phase-0.md are relevant.
