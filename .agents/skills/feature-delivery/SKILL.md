# feature-delivery

Identify acceptance criteria and relevant code/docs. Preserve documented boundaries.
Implement the scoped behavior, appropriate tests, error handling and instrumentation.
Update related contracts/docs and use focused checks while iterating.
Before completion, use the quality-gate skill and report changes, validation, risks and limitations.
See [Definition of Done](references/definition-of-done.md).
