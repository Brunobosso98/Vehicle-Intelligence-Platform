# Security policy

The foundation is intended for local engineering use. Only the latest main/0.x foundation is maintained.
For a vulnerability, use GitHub's private vulnerability reporting or a draft Security Advisory if enabled.
If unavailable, contact the repository maintainer through their published GitHub contact channel to
arrange a private report. Do not post credentials, exploit details or personal vehicle data in public issues.
No dedicated security email or response SLA is claimed. Never test against third-party or real vehicle systems.
