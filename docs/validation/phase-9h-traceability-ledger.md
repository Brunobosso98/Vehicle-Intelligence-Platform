# Phase 9H requirement traceability ledger

This ledger maps all 185 numbered specification requirements to implementation surfaces and the proof required to accept them. The exact-head PR check page is the live status source; this ledger does not substitute for those results. **Implementation is not acceptance.** The source of truth is the complete [185-section specification](../prompts/phase-9h-predictive-intelligence-ui.md).

## Execution sequence

1. Preserve the existing Next.js workspaces and build a protected, read-only operator BFF with a fixed API origin, explicit vehicle allowlist, short-lived revocable session, CSRF checks, request budgets and a generic-proxy deny rule.
2. Add a vehicle-scoped read-only 9D receipt history/detail contract, strict safe projections, GET-only 9E evidence reads and an integrity-checked static 9G research snapshot.
3. Build the integrated predictive workspace, scientific score/anomaly/reliability charts, accessible history/evidence details, independent session lifecycle and explicit synthetic demo boundary.
4. Add actual-Next/API disposable acceptance, a direct database oracle, no-write digests, adversarial security coverage, keyboard/axe checks, responsive screenshots and measured budgets.
5. Remediate current security findings; update ADR, architecture, runbook, security/evaluation reports and this ledger; run local gates and exact-head CI; push the existing branch and open (never merge) the PR.
