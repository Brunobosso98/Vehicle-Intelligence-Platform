# ADR 0006: Codex context and skills

## Status

Accepted — 2026-10-01.

## Context

Agents need targeted rules without loading a giant global document.

## Decision

Small root AGENTS, differing nested rules, four narrowly triggered skills with references.

## Alternatives considered

One PROJECT_RULES file; dozens of skills; repeated full documentation in each context.

## Consequences

Documentation must remain synchronized with commands. Repository skills are procedural guidance, not permission to mutate remote production systems.
